# 基地の見た目とアート差し替え

## 進化の仕組み（balance.json → `visuals`）

- 施設は Lv **1 / 10 / 25 / 50 / 100 / 200** で見た目が6段階に進化する（生産マイルストーンと同じ節目）。段階ごとの名前は `facilities[].tierNames`。
- 進化した瞬間：上部にバナー（操作をさえぎらない）＋専用効果音＋シーン内で光の輪と火花。
- 基地の装飾は進行状況で追加される：

## 画像の差し替え（任意）

`assets/art/` に下記の名前で PNG を置くと、その部分だけ自作の描画の代わりに画像が使われる。無いものは自動で今の描画のまま。コードの変更は不要。

| ファイル名 | 内容 | 推奨サイズ |
|---|---|---|
| `bg_{惑星ID}.png` | 背景（星空・星雲） | 1080×1080、不透明 |
| `planet_tex_{惑星ID}.png` | 惑星の表面の模様（**推奨**）。基地ビューで惑星を回すと横にスクロールする。**左右の端がつながる**横長画像 | 2048×1024（2:1）、不透明 |
| `planet_{惑星ID}.png` | 惑星本体（円形）。回転しないので、表面テクスチャが無いときだけ使われる | 1024×1024、背景透過 |
| `facility_{施設ID}_t{1-6}.png` | 施設の各段階の建物。**下端中央が地面** | 512×512、背景透過 |
| `deco_moon.png` / `deco_station.png` | 月・ステーション | 512×512、背景透過 |

- 惑星ID: `terra_nova` `glacies` `dunebell` `vulcara` `unknown`
- 施設ID: `ore_mine` `power_plant` `alloy_smelter` `research_lab` `storage`
- 全部で最大：背景5＋惑星5＋建物30＋装飾2 = 42枚。一部だけでも使える。
- 画像AI用のプロンプト（フラット絵柄）: [ART_PROMPTS.md](ART_PROMPTS.md)

## 惑星の回転（基地ビュー）

基地ビューでは1本指ドラッグで惑星が回る（慣性あり）。施設とロボットは惑星上部の輪に沿って並び、回すと裏側へ回り込む（裏側は小さく・薄く描画）。正面は5施設、裏側には表面の装飾（通信アレイ・軌道エレベーター）がある。表面の模様と夜側の街明かりも経度に沿って回る。

## 画像の取り込み

画像AIの「背景透過」PNGは、本体が少し透けていたり、背景に薄いもやが残ったりしがち。取り込み前に整える：

```bash
python3 tool/clean_sprite.py 元画像.png assets/art/facility_ore_mine_t1.png
```

本体を完全に不透明化・薄いもやと小さなゴミを除去・余白を切り詰めて高さ512pxに縮小する（光の柱など半透明の部分は残す）。

## 取り込み済み

- 鉱石採掘施設 1〜6段階（`facility_ore_mine_t1`〜`t6`）

## 小さく表示したときの見やすさ（実機サイズで検証済み）

見本画像を実際のスマホ画面サイズ（幅390pt・3倍密度）で組み込んで確認した結果：

- 屋根の色・煙突・光の柱など**大きな形と色は読める**。窓の格子・ストライプ・細い線は**ほぼ消える**。
- 細長い塔は幅が細くなりすぎる → **ずんぐりした比率**にする。
- そのためプロンプトには「約60pxでも読める太いシルエット」「細部を入れない」「幅≒高さ」を指定している。
- 統一感と個性のため、全建物に共通の目印：**紺の六角形の台座**、**オレンジの灯り1つ**、**少し斜め上からの視点**。
